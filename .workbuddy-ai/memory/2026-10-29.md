**背景**：10-28 晚写好了 `tools/extract/extract_ui.py`（从 AssetBundle 提 UI 图集 / 音频 /

### 1. 磁盘收口（用户新硬性要求：不许碰 C 盘，含缓存）

- `scripts/env.mjs`：`childEnv()` 统一给子进程覆盖 `TEMP/TMP/TMPDIR` 到 `.tmp/`，
  并在模块加载时**改写当前进程**的环境变量 —— Playwright 用 `os.tmpdir()` 建浏览器
  profile，只传给子进程拦不住（实测之前会往 `%LOCALAPPDATA%\Temp` 落目录）。
- `electron/main.ts`：app ready 之前把 `TEMP/TMP/TMPDIR` 改到 `.userdata/tmp`。
- `.venv/pip.ini`：`cache-dir = E:/pip-cache`（venv 级配置，pip config debug 可验证）。
- `.gitignore` 加 `.tmp/`。
- 审计结果：`%APPDATA%` 无应用目录；`%LOCALAPPDATA%\Temp` 里 6 个
  `playwright_chromiumdev_profile-*` 全是 10-28 23:13 的旧货，本轮没有新增。

  新增 `src/components/Glyph.tsx`（24×24 线性图标，19 个），`UIIcon` 的 `fallback`

### 4. 新增工具：布局自检

### 5. e2e 的两个真实坑

  菜单弹窗关不掉 → 后续点击全被 `.menu-dim` 拦截。现在 e2e 先 `setContentSize(1440, 900)`

- 顺带给菜单弹窗加了 **ESC 关闭**（原本只能点遮罩），e2e 改成「先按 ESC，关不掉再点遮罩」。

## 从国服 CDN 解包 UI 图集 + BGM（用户给的仓库方案）

用户给了两个仓库：`mdspeed666/BLUE-ARCHIVE-unpack`（只是网盘资源合集，不是工具）
和 `ZM-Kimu/Blue-Archive-Asset-Downloader`（可用）。按后者跑通了，**不需要装游戏**。

### 环境坑

- `uv sync` 默认写 `E:/uv-cache` 报 EACCES（沙箱只允许写工作区），改成
  `UV_CACHE_DIR="E:/Blue archive/.vendor/uv-cache"`。
- PyPI 直连超时，必须加 `--default-index https://mirrors.aliyun.com/pypi/simple`。
- 用 `uv sync --extra unitypy --no-dev`，装进 `.vendor/.../.venv`（90MB），不动项目 `.venv`。

### 关键发现：BA 用 NGUI，不是 UGUI

Bundle 里**没有 Sprite 对象**。UI 图集 = 一张 2048×2048 的 Texture2D +
一个 `MonoBehaviour(NGUIAtlas)`，后者 `mSprites[{name,x,y,width,height}]` 记录矩形。
所以 `extract_ui.py` 里那套「Sprite.image + m_Border」在国服 bundle 上完全不适用。

**坐标坑**：切图要用 `(x, y, x+w, y+h)`，**不能**做 `texH-y-h` 翻转。
UnityPy 读出的位图已是正向，再翻一次会切出错位碎片（对比图 `.tmp/crop_compare.png`）。

### 产出

- 只下了 `assets-_mx-uis` 25 个 bundle（74MB）+ `Media/audio/bgm` 365 个 ogg（399MB）。
  目录里共 69,840 项 / 12.29GB，**没有**下 table（ExcelDB.db 160MB），不碰数据库解密。
- `tools/fetch/import_ngui_atlas.py`（`npm run import:ui`）：18 个图集、1991 个精灵
  → `resources/ui/<图集>/<精灵名>.png`（17MB）+ `data/ui_atlas.json` 2009 条。
- 18 个语义别名写进 ui_atlas.json（`icon_momotalk` → `Common/Common_Icon_MoMoTalk` 等），
  前端不用改代码就能命中。主界面 16 个控件：14 个 assetbundle，2 个（AP/信用点）仍兜底。
- BGM 365 个复制到 `resources/bgm/`（382MB），文件名小写 `theme_10.ogg`，
  Windows 大小写不敏感，代码里按 `Theme_10` 查也能命中；e2e 里 `Theme_01.ogg` 的 404 已消失。

### 还没做的

- **九宫格切边**：NGUI 的 border 在 prefab 的 `UISprite` 组件上，不在图集条目里，
  需要另外解析 prefab（`ui-_mxload-prefabs` 723 个 bundle）。
- **SE**：`Media/audio/` 只有 voc_jp / voc_cn / bgm / videos，音效在 bundle 的 AudioClip 里。
- **主界面外的页面**（剧情/招募/桃信…）仍是浅色 shell，没套游戏 UI。

### 磁盘

`.baad` 452MB（下载工作区）+ `.vendor` 90MB + `resources/ui` 17MB + `resources/bgm` 382MB，
全部在 E 盘，已加进 .gitignore。

## Phase 2：九宫格切边 + SE + 页面套 UI + 重命名 shittim-chest

### 重命名
`shittim-chest` / `什亭之匣 · Shittim Chest`；package.json 加 `build.appId=dev.shittimchest.app`。
目标仓库 `chenmoulaile/shittim-chest` 未推送（GitHub connector auth-required）。

### 九宫格：border 不在 UISprite 上
- `UISprite` 组件只有 `mSpriteName / mType / mAtlas`，**没有 border**。
- 切边在 `NGUIAtlas.mSprites[i].borderLeft/Bottom/Right/Top`。
- 1991 精灵里 440 个有切边；`data/ui_nineslice.json` 440 条。
- **UnityPy 必须 `load(目录)`**，单 bundle 加载读不出 MonoBehaviour typetree（缺 MonoScript）。
- BA 精灵是**白色遮罩**，游戏里靠 NGUI mColor 上色 → 我们 `fillCenter=false` 只取形状、颜色给 CSS。
- `borderImageWidth` 要夹到原图 1/3，否则小控件四边互挤、角变形。
- prefab bundle 723 个只有 87MB，全量下载无压力。

### SE
`Media/audio/` 没有 se 目录；`Media/uis` 是图片。音效在
`assets-_mx-*-_mxcommon-_mxdependency-audio`（4 个 bundle / 16MB）→ 676 个 AudioClip，
前缀 `SFX_` 663 个。导出 `resources/se/*.wav`（82MB）+ `data/se_index.json`。
**命名对不上**：剧情用 `SE_DoorOpen_01`，提取到的是 `SFX_*`，剧情 SE 仍静音降级。

### 页面
主界面 14/16；剧情对话框（`Dreammaker/Common_Bg_Raius20px`，fillCenter=false）+ 选项按钮
（`TBG/Common_Btn_BG`）；桃信气泡（`Common/School_Chat_BG`）+ 回复按钮；招募结果卡
（`Dreammaker/Common_Bg_Raius10px`）。设置/咖啡厅/活动未做。

### 坑
浅色页面复用 `.choice-btn` 时文字是浅色（给深色对话框写的），白底上几乎看不见 →
加 `.momo-choices .choice-btn { color:#2b4257 }`。
