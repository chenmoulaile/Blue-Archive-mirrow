## 2. 关键发现

### 2.1 剧本模板与节点图天然同构

```
{{Story
|1=bgm |bgm1=Theme_10 |name1=Romantic Smile
|2=background |background2=BG_MainOffice
|5=student-text |name5=Arona |text5=Good morning, Sensei! |spine5=Arona |sequence5=03
}}
```

→ `{ "op": "script", "speaker": "Arona", "text": "...", "spine": "Arona", "sequence": "03" }`

节点类型实测分布：`script` 188165、`se` 51308、`background` 26500、`info` 13756、
`bgm` 7303、`bgmStop` 7139、`choice` 5896、`popup` 598、`memlobby` 265、`screen` 13。

其中 `memlobby` 正好标记羁绊剧情里「此处解锁记忆大厅」的位置，可以**直接把羁绊剧情和回忆大厅 Spine 串起来**。

### 2.2 剧情页全集必须用 insource 检索

按 `Main Story/` 前缀 + Category 枚举只能拿到 945 页，漏掉一半以上——羁绊剧情的正文在
`<学生>/Relationship Story/1..5` 子页面，父页面只是目录。正确做法是 CirrusSearch：

```
insource:"Story/StoryTop"  →  2479 页
```

### 2.3 背景图零映射

剧本 `{"op":"background","bg":"BG_MainOffice"}` ↔ 本地 `resources/images/gallery/1.剧情-背景图/通用内景/BG_MainOffice.jpg`。
1943 种背景引用中 1918 种可直接命中，缺的 25 种是 PV 用 CG 和几张特殊合成背景。

### 2.4 角色名 → Spine 需要变体对照表

剧本里的 `spine` 字段是显示名（`Airi (Band)`、`Akane (School Uniform)`），
而 kivo 的模型文件是 `CH0284_spr` 这种内部代号。目前靠学生表的 `given_name_en` 做基础名匹配，
621 个被引用角色里命中 493 个（79%），剩下的都是皮肤变体，需要一张
`泳装→Swimsuit / 正月→New Year / 兔兔→Bunny Girl` 的中英对照表补全（Phase 2 处理）。

## 3. 三个必须先决策的硬约束

### 3.1 Spine 运行时：4.2，不是 3.8

所有 `.skel` 二进制头标记为 **4.2.33 / 4.2.37 / 4.2.40 / 4.2.43**。
`pixi-spine` 最高支持 4.1，**渲染不了这批素材**。

| 方案 | 代价 |
|---|---|
| **A. `@esotericsoftware/spine-webgl` 4.2（推荐）** | 官方运行时，直接吃 4.2 资源；需要独立 canvas 层叠在 Pixi 上，两套渲染循环 |
| B. 找 3.8 版本的旧素材 | kivo 上没有，社区资源零散且不全 |
| C. 用 spine 官方编辑器批量降版本 | 需要正版编辑器，1700+ 模型不现实 |

影响：项目规格书里「PixiJS + pixi-spine 3.8」这一条要改。

### 3.2 wiki 不记录分支拓扑

`choice` 节点只有组号，没有全部选项文本；实际选中的那一句以 `sensei` 节点出现在后面。
**wiki 记录的是单条通关路径，不是完整对话树。**

影响：规格书里「节点图 JSON（含分支拓扑）」无法从 wiki 完整还原。播放器可以：
- 把 `choice` 渲染为「（此处存在对话选项）」标记，或
- 接社区补充分支数据，或
- 只做线性播放 + 选项位置提示

### 3.3 BGM / SE 没有合法公开源

剧情引用了 311 种 BGM、834 种 SE，但 kivo 只提供角色语音，bluearchive.wiki 只有曲目列表没有音频文件。
**这两类素材需要用户自备**（游戏内提取或购买 OST），播放器要做静音降级 + 用户音频目录映射。
