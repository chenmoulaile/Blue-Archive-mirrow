## 🐛 如果遇到问题

### 问题 1: 看不到街道场景
**症状**: 仍然看到系统室和阿罗娜 NPC  
**解决**: 刷新页面或重启 Electron

### 问题 2: 飞机不动
**症状**: 彩虹轨迹但没有飞机图标  
**解决**: CSS 动画正常，可能是渲染延迟（等待 1-2 秒）

### 问题 3: 动画卡顿
**症状**: FPS 低于 30  
**解决**: 
- 关闭其他占用 GPU 的程序
- 降低浏览器渲染质量

## 📝 开发者调试技巧

### 查看阶段状态
打开 DevTools Console，添加临时日志：
```javascript
// 在 GachaCutscene.tsx 第 80 行后添加
useEffect(() => {
  console.log('[Gacha Phase]', phase, 'at', Date.now());
}, [phase]);
```

### 手动触发跳过
按 `ESC` 键可跳过所有动画直接进入结果页

### 检查 Canvas 渲染
在 DevTools Elements 面板查找：
```html
<canvas class="star-canvas" ... />
```
应该有内容且宽高匹配父容器
